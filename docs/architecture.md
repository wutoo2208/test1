## 11. 当前滚球与循迹控制架构（2026-07-30）

> **状态**：职责分配已由用户确认；性能、控制周期、标定和故障动作仍为候选/待验证。若本节与前文“尚未定义”的历史基线描述冲突，以本节和 `DEC-015` 为当前方案方向。

### 11.1 滚球闭环

```text
K230 原始目标框 x/y/w/h + frame/time/valid
                    ↓ 球心计算、杆轴投影、像素→mm 标定
        ball_position_mm_relative_to_O
                    ↓ 球位置外环 + 速度估计/滤波
        rod_angle_ref 或 actuator_position_ref
                    ↓ 连杆几何映射、限幅和斜率限制
    D36A ST1/DIR1/EN1 → 步进电机 → 摆杆右端高度
                    ↑
       MS42CG A/B/PWM/Z：执行器位置/角度内层反馈
```

- 钢球位置反馈只来自 K230 视觉链；MPU6050 不再安装在摆杆，也不参与摆杆角度测量。
- K230 教程当前只证明可得到目标框 `x/y/w/h`。它还没有直接给出“相对 O 点的毫米距离”，必须先完成球心计算、摆杆有效轴投影、透视/尺度标定、方向定义和越界检查。
- 仅有球位置并不等于控制状态完整；至少需要从带捕获时间的连续位置估计球速。滤波必须同时考虑视觉延迟，不能用过强平滑掩盖动态。
- 步进电机不得被视为天然无误差的角度源。MS42CG 用于执行器内层位置/角度反馈或至少用于丢步监测；还需要机械零位/回零、方向、编码器计数到杆角、杆角到右端高度的标定。
- 发生视觉无效、帧号停滞、数据超时、位置跳变或 MS42CG 反馈异常时，不继续使用旧球坐标；系统进入待定义的受限安全状态。具体中立角、保持、减速或禁能策略必须在无球台架测试前单独决定。

### 11.2 底盘循迹与扰动链（MPU6050 暂不装车）

```text
LineFollower_6CH / I2C0 PA28/PA31 → 六路模拟/数字值 → 线误差 → 循迹主反馈
车轮编码器                         → 左右轮速度 ─────────→ 轮速内环
运动命令 + 编码器速度/加速度估计 + 路径曲率 ──────────→ 可选扰动前馈
OLED / I2C1 PB2/PB3               → 状态显示（不进入控制闭环）
```

- HiWonder/AiBlock LineFollower_6CH V1.0 是小车红外循迹主传感器，独占 I2C0：PA28=SDA、PA31=SCL，并经 U12 交叉线束接入。其 I²C 时序、通道左右顺序、黑线有效极性和 200 Hz 调度仍待台架验证。
- OLED 独占 I2C1：PB3=SDA、PB2=SCL，经原 MPU6050/GY 接口的重排线束接入。实物 `VDD` 对应模块正电源，`SCK` 在本模块上按 I²C `SCL` 使用；地址 0x3C/0x3D 和上拉电压待实测。
- MPU6050 当前为 `NOT FITTED`：不装摆杆、不装车体、不配置、不采样。系统因此没有直接车体姿态测量；滚球扰动前馈只保留车辆目标/编码器估计加速度、左右轮差速/路径曲率等候选，基础双闭环稳定前默认关闭。
- 若无 IMU 的简化方案不能在相同路线、速度和电池状态下满足滚球动态指标，再以新的方案决策评估是否恢复 IMU；不得在当前文档中保留隐含依赖。

### 11.3 本方案必须关闭的质疑项

1. K230 实际输出是否含帧号/捕获时间/有效标志；实际帧率、端到端延迟、抖动和连续丢帧长度是多少。
2. `x/y/w/h` 如何转换为球心沿摆杆轴线的有符号毫米位置；O 点、正方向、有效行程和 1 cm 误差如何标定与验收。
3. 球在反光、阴影、振动、快速运动和接近槽端时是否仍能稳定识别；误检时的质量指标如何定义。
4. MS42CG 的零位、绝对 PWM 与 A/B/Z 使用策略、方向、计数/圈、最大边沿频率及与杆角/右端高度的几何映射。
5. D36A+步进电机的失步、回差、机械限位、最大安全角度/高度、最大步频、加速度和失能行为。
6. 不使用 MPU6050 后，车辆目标/编码器估计加速度、左右轮差速和路径曲率能否形成符号、比例、延迟可辨识且有稳定收益的扰动前馈；若不能，是否需要重新立项恢复 IMU。

以上问题未关闭前，可以进行资料、标定脚本和模块接口设计，但不得把该方案写成已通过硬件或性能验收。
