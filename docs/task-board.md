## 1. 工作流状态

```text
待办 → 就绪 → 进行中 → 待复核 → 完成
          ↘ 阻塞
```

- 同一任务同一时间只能有一个 Owner。
- 依赖未完成时必须保持 `阻塞`。
- 没有验收证据不得标记为 `完成`。
- 任务状态变化采用追加记录，保留原始状态历史。

## 2. 优先级与负责人规则

| 优先级 | 含义 |
|---|---|
| P0 | 阻塞全部后续工作的必要输入或安全事项 |
| P1 | 直接影响评分、接口或架构的核心工作 |
| P2 | 在核心路径稳定后执行的完善工作 |

负责人类型：`Human`、`Claude`、`Codex` 或明确姓名。代理开始任务前必须读取 `docs/agent-handoff.md`、确认依赖、权限和禁止动作。

## 3. 当前阶段门槛

当前可做：

- 接收并登记正式题面、评分规则、BOM、datasheet 和接线信息。
- 对新增资料做只读提取、来源核验、需求拆解和资源冲突分析。
- 在用户明确授权下向这些新建项目文档追加记录。

当前不可做：

- 修改 `.syscfg`、源码、CCS 工程、目标配置或生成文件。
- 运行 SysConfig、生成配置、编译、链接或 CCS Build。
- 烧录、调试、探针检测、串口扫描或连接/上电硬件。
- 根据候选接口直接分配引脚或选择外设参数。

## 7. 禁止启动的工作

在 `TASK-007` 完成前，不得启动：

1. 修改 `empty.syscfg` 或任何 `.syscfg`。
2. 修改 `empty.c`、CCS 工程文件或 `targetConfigs/**`。
3. 修改或重新生成 `Debug/**`、`ti_msp_dl_config.c/.h` 等生成物。
4. 运行 SysConfig、CCS Build、编译器或链接器。
5. 烧录、调试、探针连接、串口访问。
6. 接线、上电、驱动电机或其他执行器。
7. 选择尚未确认的引脚、频率、电压、地址或算法参数。
