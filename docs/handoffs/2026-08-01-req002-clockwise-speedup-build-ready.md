# 交接：REQ-002顺时针直线提速镜像待烧录

日期：2026-08-01

## 用户现场反馈

- 上一版顺时针右转优化基本可用。
- 相同运行状态下右轮仍小幅快于左轮。
- 整车总速度略慢，无法满足比赛目标时间。

## 本轮唯一参数调整

- 左轮直线输出：600‰ → 700‰。
- 右轮先随整体提速：540‰ → 640‰，再额外降低20‰，最终为620‰。
- 实现方式：基础输出700‰，右轮固定补偿80‰。
- 保留右转弯道动态降速220‰、右转差速350‰。
- 保留左转弱恢复降速100‰、差速150‰。
- 保留最大输出800‰和300 ms软启动。

未修改PID增益、SysConfig、Pin Plan、电机方向、LineFollower、OLED、K230或无线模块。
