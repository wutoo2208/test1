## 模块边界

模块实现：

- 115200 8N1链路上固定14字节协议的字节流重同步；
- CRC-8/ATM；
- int16/uint16小端解析；
- STATUS=0/1/2；
- 丢球载荷语义检查；
- SEQ重复和跳号统计；
- 100 ms有效帧超时；
- ISR单生产者/前台单消费者128字节环形队列；
- 溢出后主动复位解析状态；
- 最新样本、可用性和诊断计数快照。

模块刻意不包含：

- DriverLib、SysConfig宏或具体IRQ名称；
- UART1/PA9硬件初始化；
- `empty.c` ISR；
- `App_init/App_service`接入；
- PID、步进电机输出或STATUS=2降权策略。

## Claude Code后续接入方式

1. 等当前第二问代码稳定后，另行修改SysConfig，将K230接收配置为UART1 RX / PA9 / 115200 / 8N1；不要猜生成名称。
2. 从生成的 `ti_msp_dl_config.h` 读取准确的UART实例、IRQ和RX FIFO宏。
3. 初始化阶段、启用UART RX中断前调用：

   `K230Link_init(Timebase_nowMs());`

4. UART RX ISR必须排空RX FIFO，每个字节仅调用：

   `K230Link_pushRxByteFromIsr(byte);`

   不要在ISR中运行PID、打印日志或执行I2C/SPI。

5. 前台循环高频调用：

   `K230Link_service(nowMs);`

6. 控制前读取：

   `K230Link_snapshot(nowMs, &sample);`

   只有 `sample.linkFresh && sample.measurementUsable` 为真时才允许使用POS/VEL。STATUS=2时 `sample.predicted` 为真，但具体降权尚未批准。

## 重要限制

- 该模块记录的是前台解析时间，不是K230图像采集时间；协议v1没有源时间戳。
- `sequenceAgeMs`只提供卡帧判定输入，不擅自冻结卡帧阈值。
- 没有冻结位置/速度合理范围、POS正方向、预测降权、PID增益或执行器限幅。
- PA8仍由K230接口保留但当前DNC，不得自动改作其他功能。
