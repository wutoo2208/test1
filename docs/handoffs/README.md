# Claude Code / Codex 会话交接说明

本目录保存**短会话交接摘要**。交接文件的目标是让新会话迅速恢复一个具体任务，不是把整段聊天、PDF 全文、终端日志或重复推理复制进仓库。

## 1. 使用时机

在以下任一时机创建交接文件：

- 当前 Claude Code 会话已经很长、准备执行 `/compact` 或准备退出；
- 一个模块资料审阅、文档任务或小型代码任务已完成，准备切换到下一任务；
- 当前任务被明确资料、用户决定或授权门槛阻塞；
- 需要由新的会话、Codex 或人工继续同一件事。

一个会话只应处理一个明确任务。完成后先写交接，再结束会话；不要依赖 `--continue` 或长对话记忆保存工程事实。

## 2. 写入规则

- 文件名使用 `YYYY-MM-DD-简短主题.md`，例如 `2026-07-29-tcrt5000-review.md`。
- 建议控制在 **800–1500 个中文字符**；只保留当前任务需要的事实。
- 必须区分：已确认事实、候选推论、未执行动作和待确认问题。
- 每条关键事实尽量链接/指向权威项目文件或原始资料页码；不要复制长文。
- 交接文件不是正式需求、决策、硬件接口或测试记录的替代品。长期有效的结论仍应按授权写入相应的 `docs/` 主文档。
- 不记录密钥、账号、私人信息，也不要粘贴大型日志、图片或 PDF 正文。

## 3. 新会话使用方式

新会话先读核心上下文：

```text
AGENTS.md
CLAUDE.md
docs/requirements.md
docs/project-state.md
```

之后只读最新且与任务直接相关的交接文件，以及任务所需的模块资料。若需要读取总计划、决策、接口、架构、测试、原始 PDF 或提取图片，应先说明它们和当前任务的关系。

## 4. 模板

```md
# 交接：<主题>

日期：YYYY-MM-DD  
会话任务：  
任务状态：完成 / 进行中 / 阻塞  
授权等级：L0 / L1 / L2 / L3 / L4 / L5

## 已确认事实
- <事实；来源文件或页码>

## 本会话结果
- 创建/修改：`<完整相对路径>`
- 未修改：<明确保护的文件或范围>

## 验证与边界
- 证据等级：资料复核 / 静态核验 / 构建验证 / 实测
- NOT RUN：<构建、烧录、串口、硬件等>

## 当前阻塞 / 待用户确认
1. <问题与所需证据>

## 下一步唯一动作
- <可领取、范围明确的下一动作>
```
