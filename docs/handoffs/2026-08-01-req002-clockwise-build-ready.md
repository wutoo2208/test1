## 顺时针非对称控制

- 直线基础：左轮600‰，右轮540‰；右轮永久降低60‰以抵消实物左偏。
- 右转（`correction < 0`）：
  - 弯道基础降速上限220‰；
  - 差速权重350‰；
  - 强右转时允许右轮降至0‰、左轮保持730‰以内，不反转。
- 左转（`correction >= 0`）：
  - 弯道基础降速上限100‰；
  - 差速权重150‰；
  - 仅保留较弱的回线纠偏能力。
- 全局最大输出800‰；300 ms软启动保留。
- KEY2中止、I2C故障、丢线、超时、返回A点和BoardSafety停车逻辑保留。

软启动结束后的典型需求：

| correction | 含义 | 左轮‰ | 右轮‰ |
|---:|---|---:|---:|
| -1.00 | 最强右转 | 730 | 0 |
| -0.50 | 中等右转 | 665 | 255 |
| -0.25 | 轻度右转 | 632 | 398 |
| -0.10 | 微小右转 | 613 | 483 |
| 0 | 直线补偿 | 600 | 540 |
| +0.50 | 左转恢复 | 475 | 565 |
| +1.00 | 最大左转恢复 | 350 | 590 |

注意：因永久右轮降速和右转优先设计，小幅左转请求会被部分抵消，这是用户明确接受的取舍。
