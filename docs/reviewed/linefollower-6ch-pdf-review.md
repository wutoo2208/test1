## 2. 模块能力和工作方式

- 六路工业级红外反射探头，由板载 32 位 ARM MCU 采集和处理。
- 板载学习按键支持分别学习背景颜色与目标巡线颜色。
- 资料宣称可处理直角、锐角、曲线、交叉/十字/丁字路口以及自适应线宽；这些是厂商功能描述，不能替代本项目 1.8±0.2 cm 黑线、0.5 m 半圆弯道和运动状态下的实测。
- 传感器只通过四线 I²C 接口向主控提供结果，不是六根独立数字 OUT。

## 4. 一键学习流程

1. 将传感器置于背景颜色上，长按学习按钮；资料称最外侧两灯闪烁，全部灯开始闪烁表示背景学习完成。
2. 将传感器置于目标巡线颜色上，短按学习按钮；资料称最内侧两灯闪烁，全部灯恢复正常速率闪烁表示成功，全部灯快闪表示失败。
3. 学习时的探头高度必须与运行高度一致。
4. 黑/白目标定义、数字状态位有效极性和掉电后学习值是否保持，仍须实物验证。

## 5. I²C 数据与寄存器

### 5.1 已获得一致支持的项目

| 功能 | 地址/长度 | 格式 |
|---|---|---|
| 六路数字状态 | 寄存器 `0x05`，1 字节 | bit0～bit5 分别对应通道 1～6；bit6/7 不应作为传感器通道使用。 |
| 六路模拟值 | 从寄存器 `0x06` 连续读取 12 字节 | 每通道 `uint16_t`，低字节在前、高字节在后。 |

教程中的 Arduino/ESP32/STM32/C51/树莓派/Jetson 示例本质上都使用 I²C。示例中的 UART/串口 115200 仅用于把读取结果打印到电脑，不是传感器 UART 协议。

### 5.2 阈值寄存器冲突

资料存在不能静默消解的冲突：

- 快速上手表格写通道阈值地址为 `18, 20, 22, 24, 26, 28`，未明确十进制还是十六进制；
- 多平台示例代码将阈值基址定义为 `0x18`，并从该地址连续读取 12 字节。

因此在实物读回或获得厂商源码前：

- 数字状态 `0x05` 和模拟值基址 `0x06` 可作为驱动候选；
- 阈值读取保持 `PROTOCOL-CONFLICT / DO-NOT-RELY`；
- 不根据表格自行展开阈值地址。

## 7. H10 与 MSPM0 静态核验

天猛星拓展板 H10：pin1～8 分别为 OUT1～OUT8，pin9=5V，pin10=GND。v1.2 将其映射为：

| H10 | MCU | I²C 能力（SysConfig 1.28 MSPM0G350X deviceData 静态核验） |
|---:|---|---|
| 1 | PB19 | 无 I²C |
| 2 | PB17 | 无 I²C |
| 3 | PA16 | 可作 I2C1 SDA |
| 4 | PA14 | 无 I²C |
| 5 | PB20 | 无 I²C |
| 6 | PB25 | 无 I²C |
| 7 | PA25 | 无 I²C |
| 8 | PA27 | 无 I²C |

结论：**H10 原始信号网络不存在一对可直接配置为硬件 I²C SCL/SDA 的引脚。** PA16 单独可作 SDA，但 H10 没有对应硬件 SCL，不能据此形成完整总线。

当前电气上更简单的候选是与 MPU6050 共用 I2C1：PB2=SCL、PB3=SDA。地址 `0x5C` 与 MPU6050 的 `0x68/0x69` 不冲突，但两块模块的上拉并联、总线电容、供电时序和失电反灌仍需台架验证。

## 8. 接线候选

### A. 推荐：不切 PCB 的共享 I2C1 线束

- 模块 5V → H10 pin9；GND → H10 pin10；
- 模块 SDA/SCL → 拓展板 GY_SDA/GY_SCL（PB3/PB2），采用可核对的 Y 形/并联线束；
- H10 pin1/2/6 保留无线，pin3/4/5/7/8 不再连接巡线模块。

### B. 单一 H10 插头：需要 PCB 隔离和桥接

- H10 pin3 先与 PA16/OUT3 原网络断开，再桥接到 GY_SDA/PB3；
- H10 pin4 先与 PA14/OUT4 原网络断开，再桥接到 GY_SCL/PB2；
- H10 pin9=5V，pin10=GND；
- 切线点、桥接焊盘和观察面尚未确认，未获后续批准前不得施工。

不推荐在 H10 GPIO 上软件模拟 I²C：它增加时序、开漏、电气和 200 Hz 调度风险，同时已有硬件 I2C1 可共享。

## 9. 待确认与验收门槛

1. 实物是否确为 HiWonder/AiBlock LineFollower_6CH V1.0，提供正反面、接口和线束照片。
2. 5 V 上电后的 SDA/SCL 空闲电压、板载上拉阻值、与 MPU6050 并联后的等效上拉。
3. I²C 可用速率、每 5 ms 调度下的总线占用、NACK/超时/总线恢复行为。
4. 通道 1～6 在车体上的左→右顺序，黑线命中时数字 bit 的有效值。
5. 六路模拟值范围、噪声、饱和、环境光、不同高度和弯道下的重复性。
6. 阈值寄存器冲突的实物读回结论。
7. H10 采用 A 方案还是 B 方案；若选 B，必须先提供拓展板 H10 附近正反面高清照片并完成断电连续性表。
8. 89 mm 模块安装后是否满足车体包络、离地高度、前悬和线缆应力要求。
