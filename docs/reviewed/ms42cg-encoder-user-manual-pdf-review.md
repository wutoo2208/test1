## 2. 六针接口与电平

### 2.1 引脚功能

| 信号 | 方向 | 手册电平范围 | 用途 |
|---|---|---|---|
| `VCC` | 输入 | `3.3–5.0 V` | 编码器供电。 |
| `GND` | 电源参考 | — | 地。 |
| `A` | 输出 | `0–VCC` | 增量编码器 A 相。 |
| `B` | 输出 | `0–VCC` | 增量编码器 B 相。 |
| `PWM` | 输出 | `0–VCC` | 单圈绝对角度 PWM。 |
| `Z` | 输出 | `0–VCC` | 每圈一次固定零点脉冲。 |

### 2.2 插头观察方向

按手册 p4 图 1 中**所示插座视角**，从左到右为：

```text
GND | Z | PWM | B | A | VCC
```

这不是用户线束/扩展板端的针序证明。接线前仍需拍摄实际 MS42CG 插头、线束和拓展板取线位置，防止镜像观察导致 VCC/GND 反接。

## 3. 手册示例与模式选择

- 手册 AB/PWM/Z 示例使用 `3V3` 给 `VCC` 供电；`A`、`B`、`PWM`、`Z` 分别接示例 MCU 的不同输入。该例程不能直接迁移为 MSPM0 引脚分配。
- SPI 模式需要移除 `R2/C2/R1/C3/R13`，并移动 `R9/R11` 的 0 Ω 电阻，随后接口变为 `VCC/MISO/MOSI/CSN/SCK/GND`。这是硬件改装，不是软件配置；本项目当前不执行。
- 手册提醒勿带电插拔；PWM 角度读取需要输入捕获资源，参数取舍由目标 MCU 和控制周期决定。

## 4. 对天猛星拓展板的受限连接结论

1. **MS42CG 不是 D36A 的输入设备**：D36A 控制头只接受 `EN/DIR/ST/ADC/5V/GND`，没有 A/B/PWM/Z 编码器输入；编码器必须最终接入 MSPM0 的可用输入/捕获资源。
2. 为保持 MS42CG 输出上限为 3.3 V，`VCC=3.3 V` 是候选供电策略；但需先确认拓展板具体 `3V3` 取线点、电源预算和线束。不得将手册允许 5 V 供电误解为 MSPM0 输入可承受 5 V。
3. `A/B` 是主速度/相位候选；`PWM` 和 `Z` 是否使用取决于摆杆角度/零点需求，必须先完成资源预算。四个输出不能因“暂不用”而任意悬空、短接或接到 D36A 控制头。
4. 当前扩展板资料只证明存在若干编码器网络及主控扩展网络；未证明 MS42CG 六针插头可直接插入任何现有座子。应按实物针序制作后续线束候选，而不是插入 TB6612、DRV8870 或 D36A 的不匹配接口。

## 5. 待确认项

1. MS42CG 安装在哪一个精确电机/机械轴上，数量是多少；是否用于摆杆位置还是车轮。
2. 实物编码器的正反面、六针线束、插头防呆方向、线色与标签。
3. 最终采用 AB、PWM、Z 的哪一种组合；是否明确不采用 SPI 改装。
4. 所有输出在 3.3 V 供电下的最高边沿频率、Z 脉宽及电缆长度。
5. 从拓展板何处取得受保护的 3.3 V/GND，以及 A/B/PWM/Z 到 MCU 的物理取线和资源预算。
