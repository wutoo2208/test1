## 2. 与现有资料的关系

- EPRO 静态来源事实见 `docs/reviewed/tianmengxing-expansion-board-v2-source-facts.md`；本照片只补充**实物正面存在性和布局观察**。
- 本项目当前实际电机驱动是 DRV8870 双路模块；正面照片中的 `TB6612模块` 接口不构成 DRV8870 的接线、机械或电气兼容性证据。
- 两块可见降压子板的具体型号、输出角色和供电对象不能从本照片确定。用户另提供的 MP1584EN 参数图片已单独审阅，见 `docs/reviewed/mp1584en-adjustable-step-down-spec-image-review.md`。

## 3. 仍缺少的关键证据

1. **拓展板背面高清照片**：需完整覆盖丝印、走线、所有排针与焊点；当前只收到正面装配照片，尚未收到背面照片。
2. 拓展板型号/版本丝印的清晰特写，以及两块降压子板的正反面、芯片丝印、输入/输出标识和电位器位置。
3. DC 插座极性、开关后的供电网络、保险/反接/过流保护、每路降压输出的目标电压与负载。
4. 若未来需要使用任何排针：该排针实物线序、对应网络、电压、方向、主控侧资源与用户授权。
