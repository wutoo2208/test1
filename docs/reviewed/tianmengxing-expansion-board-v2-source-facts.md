## 4. MSPM0 相关的已见网络名

主控扩展连接器中可见 `PA0/PA1/PA2/PA7/PA8/PA9/PA10/PA11/PA18/PA24/PA26/PA29/PA30` 与 `PB0/PB1/PB13/PB14/PB15/PB16/PB21/PB22/PB23/PB24` 等网络名，以及 `GY_SCL`、`GY_SDA`、`OUT_1`-`OUT_8`、`AIN1`-`AIN4`、`BIN1`-`BIN4`、`BEEP` 等信号名。完整焊盘号见网络矩阵。

这只能证明 EPRO 作者在 PCB 网络表中使用了这些名称；在本工程修改 `.syscfg` 前，仍必须同时核对：天猛星开发板原理图/引脚图、实际插接方向、外设资源、逻辑电平和当前生成配置。

## 5. 面向当前 H 题的冲突与待确认

| ID | 问题 | 影响 |
|---|---|---|
