- PDF p7 产品图与用户实物均为四孔蓝色板、顶部四针、底部 FPC 的 0.96 英寸 OLED 形态，属于**视觉一致/同产品族候选**。

## 3. 面向 MSPM0/天猛星接口的结论边界

1. 这份资料**确认模块方案是 I²C，而不是四线 SPI**。在当前用户批准的 v1.5 设计中，实物第三针 `SCK` 按 I²C `SCL` 使用；`SCK` 只是该载板的丝印命名，不构成 SPI 接口证据。
2. 模块输入电源可见的资料范围为 3–5 V，但 SCL/SDA 数据域明确上限为 3.3 V。即便模块从 5 V 供电，也**不得**把 5 V 上拉的 I²C 线接入 MSPM0。
3. PDF p8 对指定修订显示 SCL/SDA 4.7 kΩ 上拉到稳压后 `VCC`；但实物为 `GM009605V4.3`，必须确认其稳压输出/上拉实际电平后，才能判定与 MSPM0 3.3 V I²C 的直接兼容性。
4. 当前 frozen v1.5 不再使用旧 U8 OLED 口，而是使用原 MPU6050/GY 接口：GY pad1=5V、pad2=GND、pad3=PB2/I2C1 SCL、pad4=PB3/I2C1 SDA。由于 OLED 实物针序为 `GND/VDD/SCK/SDA`，必须按信号重排，禁止四芯直通；本结论只冻结设计，不授权接线或修改 `.syscfg`。
