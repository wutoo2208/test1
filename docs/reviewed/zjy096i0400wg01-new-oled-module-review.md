## 1. 来源范围与实物对应性

- PDF p7 产品图与用户实物均为四孔蓝色板、顶部四针、底部 FPC 的 0.96 英寸 OLED 形态，属于**视觉一致/同产品族候选**。
- 实物背面可见 `GM009605V4.3`，而 PDF 没有在已核对页面中给出这个 PCB 丝印；因此不能声称照片板与 PDF 中载板为逐元件、逐修订一致。
- PDF p7/p8 的模块接口写 `GND/VCC/SCL/SDA`；实物顶部丝印写 `GND/VDD/SCK/SDA`。在未确认该修订版 PCB 走线前，`VDD↔VCC`、`SCK↔SCL` 只能作为候选对应关系。

## 3. 面向 MSPM0/天猛星接口的结论边界

1. 这份资料**确认模块方案是 I²C，而不是四线 SPI**；实际丝印 `SCK` 不能被直接解读为 SPI 时钟，因为 PDF 对同一产品族的第三针定义为 `SCL`。
2. 模块输入电源可见的资料范围为 3–5 V，但 SCL/SDA 数据域明确上限为 3.3 V。即便模块从 5 V 供电，也**不得**把 5 V 上拉的 I²C 线接入 MSPM0。
3. PDF p8 对指定修订显示 SCL/SDA 4.7 kΩ 上拉到稳压后 `VCC`；但实物为 `GM009605V4.3`，必须确认其稳压输出/上拉实际电平后，才能判定与 MSPM0 3.3 V I²C 的直接兼容性。
4. 天猛星 V2.0 EPRO 的 OLED 口为 `GND/5V/PA1/PA0`，尚未证明其针序与本模块实物相同，也尚未确认 PA1/PA0 是 I²C SCL/SDA。不得据此接线或修改 `.syscfg`。
