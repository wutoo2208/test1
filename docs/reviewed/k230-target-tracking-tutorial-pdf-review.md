### 引脚结论

1. 本教程能确认 K230 侧用于该示例 UART 的标号是 **`IO9`（TXD）** 与 **`IO10`（RXD）**。
2. 不能从教程中的 `A21/A22` 推导为 `PA21/PA22`，更不能直接连到当前天猛星开发板的 `PA21/VREF-` 或其他 MCU 引脚。当前板级资料明确将 `PA21/VREF-` 视为参考电压网络，禁止将其当作普通 UART GPIO。
3. 教程图中的 `VCC` 具体是 5 V、3.3 V 还是经由何种电源路径提供，需由实物板丝印/原理图和供电测量确认；不能因写有 `5V → VCC` 就假定可安全接入。
4. 在精确 K230 板型、IO9/IO10 逻辑电平、天猛星物理排针、UART 实例/复用和电源预算关闭之前，本资料**不形成 Pin Plan 或接线指令**。
5. docs/pin-plan/mspm0g3507-pin-plan-candidate.md 中已有 PA8/PA9 作为视觉 UART 的 conditional 候选；该候选不是由本教程的 A22/A21 推导而来，也不是已确认接线。本教程不能替代其物理排针、电平和 UART 参数核对。

## 4. 教程观察到的行为

- K230 保存为离线程序并重启后，画面先出现绿色框；对准目标并等待后绿色框变红，移动目标时红框跟随。
- 教程明确提醒不要快速移动被跟踪目标，否则可能无法正确跟踪。
- 该示例以超声波模块作为被跟踪目标；没有展示钢球、凹槽摆杆、场地振动、逆光、遮挡或快速运动下的表现。

## 5. 与 H 题的关系

- 该教程为“摄像头检测”提供一个 **K230 侧目标框坐标 → MSPM0 串口传输** 的候选起点。
- 它本身**没有**说明车载视频发送、场外接收、稳定实时显示、录像、回放或接收端设备，故不能单独证明满足 H 题 `REQ-001` 的图传要求。
- `x/y/w/h` 还不能直接作为 H 题钢球位置控制输入；需要先确定相机安装、视野覆盖完整摆杆、像素到毫米/厘米标定、目标丢失和延迟处理。

## 6. 待确认项

1. 用户实际 K230 的精确板型、摄像头型号、正反面和端口丝印是否与教程图片一致。
2. K230 `IO9/IO10` 的 UART 电平、上电默认状态和是否可直接与 MSPM0 3.3 V 逻辑相连。
3. 教程 `A21/A22` 在所示 MSPM0 教程板上的精确 MCU 网络/物理针脚；它们与当前天猛星板的对应关系不能猜测。
4. K230 - MSPM0 原始 UART 帧的完整格式、波特率、刷新率、校验、超时和失帧行为。
5. 车载视频发送、场外接收、显示、录像和回放的实际硬件链路。
6. 目标跟踪对象是否能稳定锁定钢球；相机是否能覆盖完整摆杆；标定精度能否支持题目 1 cm 误差要求。
