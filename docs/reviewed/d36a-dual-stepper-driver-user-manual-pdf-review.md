## 2. 控制头功能

| 信号 | 功能 | 当前连接状态 |
|---|---|---|
| `ST1` / `ST2` | 步进电机 1 / 2 的 STEP 输入；**上升沿有效**，每个上升沿转一个当前细分步距角。 | MCU 定时器输出候选，未分配。 |
| `DIR1` / `DIR2` | 步进电机 1 / 2 方向控制。 | MCU GPIO 候选，未分配。 |
| `EN1` / `EN2` | 步进电机 1 / 2 使能；低电平休眠、高电平使能。 | MCU GPIO 与上电安全态候选，未分配。 |
| `ADC` | 手册称为读取输入电源电压的 `1/11` 信号。 | MCU ADC 候选，未分配；比例和精度未实测。 |
| `5V` | 手册说明为 5 V 电源输出，可供其 STM32/Arduino 示例核心板。 | 不得直接并入天猛星或现有 5 V/3.3 V 电源域。 |
| `GND` | 电源地。 | 共地路径与回流待电源方案确认。 |
| `Vin+` / `Vin-` | 手册示例接外部 12 V 电源正/负极。 | 手册未给出完整允许输入范围、瞬态与保护条件；不能自动认定 3S 电池/拓展板连接已安全。 |

按手册 p10/p11 方向，控制头为双列接口，左列含 `ADC/EN2/DIR2/ST2/GND`，右列含 `5V/EN1/DIR1/ST1/GND`。实际板子控制头丝印在背面，接线前必须以实物背面为准。

## 3. 拨码与安全边界

- 拨码 `1–3` 设置细分，`4–6` 设置电流；开关“导通=1、断开=0”的拨码真值表不能直接等同于芯片 MS 引脚高低电平。
- 手册指出细分和电流设置均对两路共同生效。
- 模块带风扇，手册称默认持续运转；风扇、散热片和高电流档位均需要机械防护与热验证。
- 手册特别警告：电机相电压是快速方波，不应只靠万用表判断驱动是否正常；后续若获授权，应按安全流程使用示波器和受限台架验证。

## 4. 与 MS42CG 和天猛星拓展板的关系

1. MS42CG 是电机轴编码器，`A/B/PWM/Z` 输出**不接入 D36A**；D36A 只负责两相步进电机绕组和 `ST/DIR/EN` 控制。
2. 若 MS42CG 被安装在 D36A 驱动的步进电机轴上，系统至少包含两套独立接口：

```text
MSPM0 → ST / DIR / EN → D36A → A+/A-/B+/B- → 两相步进电机
MS42CG A/B/PWM/Z → MSPM0 输入/捕获资源
```

3. 这只是功能链路，不是已批准接线。当前拓展板原有 TB6612 接口、双路 DRV8870 模块与 D36A 的 STEP/DIR/EN 接口彼此不直接兼容。
4. D36A `5V` 是输出而非已审核的系统供电源；禁止借此给 MSPM0、K230、MS42CG 或其他模块反向供电，除非后续电源树审查明确批准。
