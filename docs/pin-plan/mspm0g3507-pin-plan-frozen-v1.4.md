# MSPM0G3507 Pin Plan v1.4 — KEY2 实物映射修订

> **状态**：`USER-VERIFIED HARDWARE MAPPING / APPROVED FOR PA21 GPIO / VALIDATION PENDING`  
> **日期**：2026-07-31  
> **基线**：`mspm0g3507-pin-plan-frozen-v1.3.md`。除下表外，v1.2/v1.3 的其他分配与安全边界不变。

## 实物修订

| 引脚 | v1.4 Owner | 配置/策略 | 证据等级 |
|---|---|---|---|
| PA21/VREF- | `START_BUTTON / KEY2` | 用户实物确认 KEY2 连接 PA21；GPIO 输入、内部上拉、低有效、30 ms 轮询消抖；用户明确接受 PA21 不再作为 VREF- 使用 | SysConfig/build + 台架：松开=0、按住=1、松开恢复=0；一次消抖事件 |
| PB21 | DNC | 用户实物确认当前板上 PB21 空置；从 SysConfig 移除 | 用户实物陈述；PB21 原始电平按键测试无变化 |
| PB27 | DNC | 延续 v1.3：蜂鸣器类型/极性未知，保持物理断开且固件不配置 | 静态/构建/台架安全策略 |

## 冲突与后果

- 本修订覆盖旧文档中“PB21 是当前实物按键”的结论；该结论不适用于当前实物组合。
- PA21 是 MSPM0G3507 的 VREF- 特殊引脚。按用户批准改作 KEY2 后，本工程不得再把 PA21 用作 ADC 外部参考负端。
- 该修订只授权启动按键映射，不授权 TIMA0 PWM、电机 Adapter、D36A 动作或整车运动。
- 第二问的 UART/RF 仍只允许状态查询，不能作为启动路径。

## 调试经验

当 SysConfig、构建和软件状态均正常，但实物操作完全不改变输入时，应优先核对板卡修订、扩展板网络、丝印、排针方向和实物连续性；不得仅凭旧原理图或历史文档继续假设软件错误。
