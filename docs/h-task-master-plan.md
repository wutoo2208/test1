## 1. 目标、评分与关键路径

### 1.1 题面核心指标

| 项目 | 分值 | 关键指标 |
|---|---:|---|
| 摆球位置监测图传 | 6 | 摄像头检测；车载发送；场外实时显示、完整录像和回放 |
| 单圈循迹停车 | 16 | 一圈 `<=20 s`，停车偏差 `<=2 cm` |
| 静止滚球定位 | 13 | O→+5 cm→-5 cm，`<=5 s`，两处最大误差 `<=1 cm` |
| A→B 动态中心平衡 | 20 | `<=8 s`，球位置误差 `<=1 cm` |
| 单圈中心平衡 | 20 | `<=30 s`，全程误差 `<=1 cm` |
| 单圈任意位置平衡 | 20 | `<=30 s`，全程指定位置误差 `<=1 cm` |
| 其他 | 5 | 细则待裁判说明 |
| 设计报告 | 20 | 方案、理论、电路程序、测试数据、规范性 |

图传虽然只有 6 分，却同时是题面强制的球位置检测方式和动态误差证据链，必须作为 P0，而不是最后补装。

### 1.2 几何和合规红线

- `[题面事实]` 车体投影不超过 `35 cm × 25 cm`。
- `[用户陈述]` 当前底盘标称 `32 cm × 24 cm`：长度名义余量 3 cm，宽度总余量仅 1 cm。
- `[题面事实]` 摆杆为 25 cm PPR 水管槽，整个摆杆不得超出车身。
- `[题面事实]` 左端铰接，支点距车板高度 `h >= 5 cm`。
- `[题面事实]` 循迹只能使用红外光电模块；正式运行不得人工干预或遥控。
- `[题面事实]` 显示屏不大于 2 英寸，启动即计时并显示。
- `[题面事实]` 钢球位置检测必须使用摄像头，画面覆盖完整摆杆。

### 1.3 开发顺序原则

1. 先闭合合规、机械、供电、视觉和安全。
2. 先分别完成底盘闭环与静止滚球闭环。
3. 再做耦合：低速直线 → A-B → 单圈中心 → 任意目标。
4. 报告、视频和遥测从第一次实验开始积累，不在最后补写。
5. 每个阶段保留可回退版本，不以未稳定的高分项破坏基础得分项。

## 2. 系统总体边界

```text
本地按键 / 模式 / 目标
          │
          ▼
┌──────────────── MSPM0G3507 实时主控 ────────────────┐
│ 状态机、计时、OLED、蜂鸣器、安全与故障              │
│ 八路红外 → 线误差 → 循迹外环                         │
│ 编码器 → 左右轮速度内环 → DRV8870 → MG513X          │
│ K230球坐标/时间戳 → 球位置外环 → MS42CG执行器内层   │
│ 串口参数与遥测（仅开发调试，不作比赛遥控）           │
└───────────────────────────────────────────────────────┘
          ▲                              │
          │ 球坐标数据                   │ 执行器命令
          │                              ▼
┌─────────┴──────────┐          ┌──────────────────┐
│ 机载摄像与视觉处理 │          │ 摆杆、连杆、限位 │
│ frame/time/pos/valid│          │ MS42CG位置/角度反馈│
└─────────┬──────────┘          └──────────────────┘
          │ 同源或可对应的视频
          ▼
车载发送端 → 场外接收/显示/存储 → 完整录像与回放
```

### 2.1 MSPM0 职责

- 红外采集、校准、线位置计算和丢线检测。
- 编码器采集、速度估计、左右轮闭环和电机命令。
- 摆杆执行器控制；通过 MS42CG 和机械零位/连杆标定获取执行器位置/杆角，不使用摆杆 MPU6050。
- 接收带时间信息的球位置；检查有效性、数据年龄和跳变。
- 状态机、计时、按键、OLED、蜂鸣器、保护和故障锁存。
- 输出调试遥测和可版本化参数。

### 2.2 机载视觉最小数据合同

```text
protocol_version
frame_id
capture_timestamp
ball_position_mm_relative_to_O
valid
quality_or_confidence
optional_exposure_or_drop_flags
```

MSPM0 记录接收时刻并计算数据年龄。坐标过期、无效、帧号停滞或异常跳变时，不得持续使用旧值。

### 2.3 图传边界

- 同一摄像头/视觉链路优先同时满足检测、全杆画面、发送、显示、录像与回放。
- 若使用两个摄像头，必须证明控制坐标与裁判录像可对应，并先确认合规性。
- NRF24L01+ 不适合实时视频；最多作为低带宽遥测候选，且不得演变为比赛遥控。
- MSPM0 不承担完整视频编码或传输。

## 5. 关键缺口与采购清单

### 5.1 P0 缺口

| 缺口 | 必须确认的参数 | 推荐起点 | 备选/风险 |
|---|---|---|---|
| 摄像头与机载视觉 | 视场、分辨率、帧率、曝光、算力、坐标输出、延迟、尺寸/重量 | 能在车上输出球坐标并提供完整视频的视觉方案 | 单纯录像摄像头不能自动构成控制反馈 |
| 视频发送/接收/存储 | 频段、延迟、抗干扰、供电、录像格式、容量、回放、封存 | 车载发送 + 场外接收显示/录制成套方案 | NRF24 不可替代视频链路 |
| 摆杆执行器 | 速度、扭矩/推力、行程、回差、死区、反馈、尺寸、堵转电流 | 高速数字舵机 + 连杆作为首个评审基线 | 普通推杆可能慢且回差大 |
| 电池与保护 | 化学体系、串数、电压、容量、倍率、BMS、充电、连接器 | 按电机/执行器/视觉峰值预算选型 | 未知电池会阻塞全部功率设计 |
| 急停/总断能 | 额定电压/电流、断开域、安装位置 | 可直接切断电机和执行器功率的方案 | 软件 STOP 不能替代断能 |
| 机械连接件 | 舵盘、连杆、支架、限位、紧固件 | 先做 1:1 包络与扫掠 | 未知尺寸执行器可能无法装入 |
| 钢球与标定 | 直径、质量、材质、圆度、刻度、照明 | 按题面约 1 cm 球和槽外刻度 | 反光、阴影会影响视觉 |

采购/选型记录至少包含：精确型号、实物尺寸/质量、供电范围、静态/峰值/堵转电流、速度、扭矩/推力、行程、回差、协议、端到端延迟、交期、替代件和来源文件。

### 5.2 摄像与图传必须关闭的问题

- 视觉处理在车上还是场外？推荐车上完成坐标提取，避免控制依赖无线回传。
- 检测画面和裁判录像是否同源、能否逐帧对应？
- 相机固定在车体还是随杆？两者的透视、运动质量、振动和布线影响需实测。
- 全 25 cm 摆杆是否始终在画面内，1 cm 误差是否可可靠判读？
- 曝光、运动模糊、钢球高光、槽壁反射、遮挡和丢帧如何处理？
- 采样到执行器生效的总延迟和抖动是多少？
- 每次测试如何自动关联 `run_id`、视频、参数和遥测？

## 6. 机械与摆杆执行器评审

### 6.1 包络门槛

- 25 cm 摆杆优先沿 32 cm 长度方向布置，不沿 24 cm 宽度横放。
- 32 cm 长度相对摆杆仅有约 7 cm 名义余量，仍需容纳铰链、连接点和安全间隙。
- 24 cm 宽度相对题面上限只剩总计 1 cm；必须测量轮胎、螺钉、支架、摄像头、线缆在内的完整投影。
- 全摆角状态都要检查摆杆、连杆和线缆不越界、不碰轮胎、不进入机械死点。
- 支点高度满足 `h >= 5 cm`；机构固定后重新测量。
- 先制作 1:1 纸样或 CAD，标注重心、扫掠、视场和维护空间，再采购尺寸未知执行器。

### 6.2 执行器方案排序

| 方案 | 优点 | 主要风险 | 进入实测前需要 |
|---|---|---|---|
| 高速数字舵机 + 连杆 | 控制简单、响应通常较快、易换机械增益 | 死区、回差、堵转电流、内部环不可观测 | 精确速度/扭矩/尺寸/电流；连杆几何与限位 |
| 带反馈高速线性执行器 | 运动直观、可有位置反馈 | 速度/回差/体积可能不满足 | 负载速度、行程、回差、反馈精度和电流实测 |
| DC 电机 + 减速/连杆 + 角度反馈 | 可自定义高带宽闭环 | 开发量、机械复杂度和安全风险高 | 驱动、编码/角度反馈、限位和控制资源 |
| 普通线性推杆 | 易理解、保持力可能较高 | 通常较慢、回差大、尺寸长 | 只有规格证明满足 5 s 和动态扰动后才采用 |

MG513X 保留给底盘，不作为摆杆应急执行器。

### 6.3 机械验收清单

- [ ] 摆杆长度、槽形、平直度和槽内表面符合题面。
- [ ] 铰链轴线稳定、间隙和摩擦可重复。
- [ ] 钢球尺寸、质量和表面状态已记录。
- [ ] 执行器全行程无死点、卡滞、碰撞和越界。
- [ ] 有机械限位；软件限位不作为唯一保护。
- [ ] 相机全程无遮挡，刻度和球清晰。
- [ ] 电池、执行器和相机安装后重心不过度偏移。
- [ ] 线缆有应力释放，不拉扯摆杆或进入轮区。

## 7. 供电域与安全

### 7.1 电源域

| 电源域 | 负载 | 当前状态 |
|---|---|---|
| `BATT_RAW` | 车载电池原始输入 | 电池规格待定 |
| `MOTOR_POWER` | 两个 MG513X、DRV8870 功率级 | 电压/峰值/堵转预算待手册 |
| `ACTUATOR_POWER` | 舵机/推杆/DC 摆杆执行器 | 执行器未选 |
| `VISION_VIDEO_POWER` | 摄像头、机载视觉、视频发送 | 设备未选 |
| `LOGIC_SENSOR_POWER` | MSPM0、灰度、编码器逻辑、IMU、OLED、按键 | 逐模块电压待核 |
| `FIELD_RX_POWER` | 场外接收、显示、存储 | 独立于车载供电规划 |

每个域必须记录：标称/允许电压、静态/峰值/启动/堵转电流、变换器余量、纹波、热、地和回流、保险、反接、浪涌/续流、上电顺序和断电行为。

### 7.2 急停和故障原则

- 急停优先切断电机与摆杆执行器功率；是否保留逻辑/录像供电由最终电路决定。
- 上电、复位和通信中断默认无危险运动。
- 不因库存中有“隔离 MOSFET”就认定已经隔离；共地/隔离必须由实际拓扑证明。
- MP1584 使用前进行额定负载、温升、纹波和电机/舵机瞬态测试。
- 发现棕断、过流、异常发热或图像受电机噪声影响时，先处理供电和布线，不用软件参数掩盖。

## 11. 状态机

```text
BOOT
  → SAFE_INIT
  → IDLE
  → CALIBRATION ─────────────┐
  → ARMED                    │
      ├→ TEST_LINE_LAP_STOP  │
      ├→ TEST_BALL_STATIC    │
      ├→ TEST_AB_CENTER      │
      ├→ TEST_LAP_CENTER     │
      └→ TEST_LAP_ARBITRARY  │
             → STOPPING      │
             → COMPLETE      │
                             │
任意状态 → FAULT ────────────┘
任意状态 → ESTOP → 人工断能/检查/复位
```

### 11.1 状态规则

- `BOOT/SAFE_INIT`：运动输出安全，检查配置和故障锁。
- `IDLE`：允许摆放球、选择本地模式，不计时、不运动。
- `CALIBRATION`：只允许受限标定动作；车辆运动与执行器动作分别授权。
- `ARMED`：锁存测试模式、球目标、参数版本、录像/遥测 `run_id`；前置条件不满足则拒绝启动。
- 各 `TEST_*`：只执行该评分场景允许的行为，不接受远程改变路径/目标。
- `STOPPING`：先安全减速/停止，再冻结计时和显示。
- `COMPLETE`：保存结果，不自动重启。
- `FAULT`：传感器失效、视觉超时、丢线、驱动异常、控制超期等进入安全动作并记录原因。
- `ESTOP`：最高优先级，不能被普通命令清除。

## 12. 控制算法与调参

### 12.1 车辆级联控制

```text
八路红外 → 线位置估计 e_line
             ↓
        循迹外环（候选 PD/PID）
             ↓
      车速目标 + 左右差速目标
             ↓
左右轮速度内环（编码器反馈）
             ↓
     PWM/方向/制动 → DRV8870
```

要求：

- 先校准红外原始值、黑白方向和丢线条件。
- 左右轮分别闭环，处理死区、饱和和电池变化。
- 增加速度/加速度限幅，动态平衡模式使用更保守速度曲线。
- A 点停车采用状态、启停线、圈数和减速窗口联合判定，避免单次黑线误触发。
- 维护至少“循迹停车专项”和“滚球平衡专项”两套受控速度配置。

### 12.2 球杆级联控制

```text
ball_ref - K230_ball_pos_mm → 球位置外环 + 球速估计
                                   ↓
                         rod_angle_ref / actuator_position_ref
                                   ↓
                     连杆几何映射、限幅和斜率限制
                                   ↓
           MS42CG 位置/角度内层 → D36A STEP/DIR/EN
```

要求：

- 先确认 K230 像素坐标、球相对 O 点毫米位置、MS42CG 计数、杆角、右端高度和执行器命令的正方向与单位。
- 视觉数据按捕获时间理解，不把接收时间当采样时间；若协议没有帧号/捕获时间，必须先补齐或量化其误差。
- 使用数据年龄门槛、异常点剔除和丢帧处理。
- PID 候选需具备积分限幅/冻结、抗饱和、微分滤波和输出限幅。
- 不把步进电机指令脉冲视为必然到位；MS42CG 用于闭环或丢步监测，并处理回差、延迟、机械零位和实际杆角偏差。
- 设计报告建立小角度球—杆模型与车辆加速度扰动项；模型参数由实物辨识修正。

### 12.3 前馈候选

只有基础反馈稳定且同步日志证明扰动重复后再启用：

- 车辆目标或编码器估计纵向加速度；
- 车体 MPU6050 加速度/角速度（不用于摆杆角度反馈）；
- 已知路径曲率/转弯状态；
- 执行器重力或连杆几何补偿。

未辨识符号、比例和延迟前，前馈默认关闭。

### 12.4 调参顺序

1. 单位、零点、方向、时间戳和故障值。
2. 单轮与左右轮速度环。
3. 低速循迹外环和丢线恢复。
4. D36A+步进电机+MS42CG 执行器位置/杆角内层（无球、完成回零与限位）。
5. 静止球位置外环：中心 → 小位移 → +5/-5 cm。
6. 评估并逐项加入前馈。
7. 低速直线耦合。
8. A-B 中心。
9. 单圈中心。
10. 任意目标位置。

本计划不预填控制周期、PID 数值、滤波系数或前馈增益。

## 15. 降级路线

1. 保住摄像头检测、合规图传、完整录像和回放。
2. 保住单圈循迹停车。
3. 保住静止 O→+5→-5 cm。
4. 动态项目按 A-B → 单圈中心 → 任意位置推进。
5. 视觉算力不足时，优先换为可机载输出球坐标的视觉模块，同时保留合规视频链路。
6. 普通推杆速度/回差不满足时，回到高速数字舵机+连杆；之后才评估带反馈高速线性执行器或 DC 电机+角度反馈。
7. 不把 MG513X 从底盘拆去做摆杆，不把 NRF24 当视频链路。
8. 动态控制不稳定时，冻结底盘、图传和静止滚球的可得分版本。
9. 冲刺后段不引入未经完整测试的新电源、执行器、视觉架构或不必要模块。
10. 若中心单圈稳定而任意点不稳，保留中心项目，不以最后 20 分破坏前序 20+20 分。
