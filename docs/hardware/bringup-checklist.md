# MSPM0G3507 电赛工程 Bring-up 检查表

## 接线前

- [ ] 阅读 `board-pinout.md`、`board-power-debug.md`、`resource-conflicts.md`。
- [ ] 为每个模块确认供电电压、逻辑电平、最大电流和 GND。
- [ ] 电机电源与开发板逻辑电源分离；仅建立可靠共地。
- [ ] 未使用 `PA2-PA6`、`PA18-PA20`、`PA21/PA23`、`PB6-PB9` 作为普通外设。
- [ ] 外部 I2C 上拉最终为 3.3 V。

## SysConfig 前

- [ ] 先建立官方例程并成功在 XDS110 下载。
- [ ] 先只启用 UART0 日志、PB22 LED、PB21 按键；验证最小基线。
- [ ] 新增一个外设后重新生成并构建，不手改生成文件。
- [ ] 为 PWM、ADC、编码器、I2C 明确记录定时器/通道/引脚选择。

## 电机首次上电

- [ ] 电机轮子悬空或脱离赛道。
- [ ] 电机驱动输入为安全低电平/PWM=0。
- [ ] 有保险丝、开关、可限流电源或可快速断电方案。
- [ ] 先验证单侧电机低占空比，再验证编码器方向与计数。
- [ ] 串口日志包含时间、目标值、实际值、PWM 与故障标志。

## 资料追溯

- [ ] 所有引脚和电压结论都能追溯到 PDF 页码。
- [ ] 不确定项明确标记“待确认”，不让 AI 猜测。
