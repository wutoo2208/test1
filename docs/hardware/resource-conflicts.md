# 板载资源冲突表

> 目的：在创建 SysConfig 之前先把板载占用资源写清楚，避免“代码能编译但硬件不能用”。

| 资源 | 已连接到 | 风险 | 项目规则 |
|---|---|---|---|
| `PA10/PA11` | CH340E、UART0、下载相关网络 | 外接模块可能干扰串口/下载 | 预留作日志 UART0。 |
| `PA18` | BSL 按键与下拉网络 | 启动模式异常 | 不作普通 GPIO。 |
| `PA19/PA20` | SWD 调试接口 | 无法下载/调试 | 永久保留。 |
| `PB6-PB9` | 板载 SPI Flash | SPI 冲突、启动/存储异常 | 不作为默认外设。 |
| `PB8/PB9` | SPI Flash + LCD H8 | 双重占用 | 使用 LCD 前先处理 Flash 冲突。 |
| `PB21` | 用户按键 | 按下为低电平 | 可作为输入，但不要外接强推挽输出。 |
| `PB22` | 用户 LED | 高电平点亮，有 2 kΩ LED 负载 | 可作状态输出，不作高速/精密信号。 |
| `PA2-PA6` | ROSC / 两组晶体 | 时钟异常 | 永久保留。 |
| `PA21/PA23` | ADC 参考网络 | ADC 精度/电压风险 | 永久保留，除非专门配置参考电压。 |

## 电赛模块接入前的最小检查

- 灰度模块若输出 5 V，先做 5 V→3.3 V 电平转换或改用 3.3 V 供电。
- 编码器 A/B 信号先测量空闲高电平与实际频率，再选定时器捕获/编码器方案。
- DRV8870 的电机电源与开发板 USB/3V3 分离，所有系统 GND 共地。
- OLED 与 MPU6050 优先使用同一 3.3 V I2C 总线；确认地址不冲突。
- 任何接到 SWD、BSL、NRST、VREF 的外部线都必须二次复核。
