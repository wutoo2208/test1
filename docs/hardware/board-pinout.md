# 引脚、接口与分配约束

> 来源：引脚图 p1；原理图 p1 与 p3。

## 首先保留，默认不分配给比赛外设

| 引脚/资源 | 原因 | 规则 |
|---|---|---|
| `PA2/ROSC` | 板载 ROSC 精密电阻网络。 | 禁止作为普通 GPIO。 |
| `PA3`、`PA4` | 板载 32.768 kHz 晶体。 | 不分配为普通外设。 |
| `PA5`、`PA6` | 板载 40 MHz 晶体。 | 不分配为普通外设。 |
| `PA18/BSL` | 连接 BSL 按键和启动相关电路。 | 除非明确测试 BSL，禁止用作比赛功能 GPIO。 |
| `PA19/SWDIO`、`PA20/SWCLK` | XDS110/SWD 调试下载。 | 永久保留；外设接线不得占用或强驱动。 |
| `PA21/VREF-`、`PA23/VREF+` | ADC 参考电压网络。 | 没有阅读参考电压选择原理图前不得使用。 |
| `PB6`、`PB7`、`PB8`、`PB9` | 板载 SPI Flash；PB8/PB9 还接 LCD 接口。 | 不作为电机/编码器/灰度的默认候选。 |
| `PA10/U0TX`、`PA11/U0RX` | 原理图记录为板载 CH340E 串口网络。 | 当前未接 UART0 外设/线束；不能视为可用日志、调参或下载端口。 |
| `PB21`、`PB22` | 板载按键与 LED。 | 可用，但要接受板载电路行为。 |

## 推荐的接口使用方向（尚未写入 SysConfig）

| 需求 | 推荐方向 | 原因与注意事项 |
|---|---|---|
| MPU6050 + I2C OLED | I2C0：`PA0/PA1` | 原理图有 3.3 V 默认开漏上拉选择；所有 I2C 外设必须以 3.3 V 逻辑工作。 |
| PID 日志 / 参数调参 | UART0：`PA10/PA11`（未启用） | 原理图 CH340E 路由不等于当前链路；须先完成实物/COM 验证。 |
| 状态提示 | `PB22` | 板载 LED，高电平点亮。 |
| 人工模式/启动 | `PB21` | 板载按键接地，固件中启用上拉。 |
| 灰度模块模拟量 | 选引脚图中标有 `A0_x` / `A1_x` 的外接 ADC 引脚 | 先确认灰度模块输出是模拟量还是数字量、输出电平是否为 3.3 V；再让 SysConfig 分配 ADC。 |
| 电机 PWM / 编码器 | 选未保留且具有相应 TIMER 功能的外接引脚 | 必须先由 SysConfig 确认定时器通道、编码器边沿/捕获资源及 DMA/中断需求。 |

## 扩展接口提示

- U21/U22 将大量 GPIO、ADC、3V3、5V、GND、NRST、BSL、SWD 等引出；具体物理排针号请直接查看引脚图 p1 或原理图 p3，接线前不要仅依据文本提取结果。
- U20 是调试与下载接口，包含 UART0、SWDIO、SWCLK、3V3、5V 和 GND。
- H8 是常用 SPI LCD 接口；其供电选择依赖 0 Ω 电阻配置，接 OLED/LCD 前应确认模块工作电压与跳线状态。
