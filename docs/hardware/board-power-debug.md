# 电源、参考电压与调试通道

> 来源：原理图 p1（core）、p2（power）、p3（extension）。

## 板载电源路径

```text
USB-C VBUS
  -> ESD 保护 D1
  -> F1（500 mA）
  -> VBUS_5V / +5V
  -> 板载 DC-DC U9 + L1
  -> 3V3
  -> F2（500 mA）
  -> EXT_3V3 外部排针
```

## 重要电源规则

1. `VBUS_5V` 来自 USB-C，经 F1 500 mA 保护；它不适合承担双直流电机等高峰值负载。
2. `EXT_3V3` 由板载 3V3 经 F2 500 mA 输出。外接传感器应先估算电流，禁止把电机、驱动器 VM 或大电流舵机电源接在此轨。
3. 电机驱动应使用独立电机电源母线；与开发板只在合理位置共地。不要让电机启动电流经过开发板 USB/3V3 供电路径。
4. 原理图明确提示 `VCORE` 是内部稳压内核电源输出，不能外接供电或挂载外部负载。
5. 数字地与模拟地通过 R42（0 Ω）单点相连。模拟 ADC/参考电压接线要避免与电机回流共用细长地线。

## ADC 参考电压

`PA23/VREF+` 有三种原理图选择来源：

- 板载 3V3 经磁珠与滤波网络；
- 外部参考电压芯片 U23；
- 外部排针 `EXT_PIN_VREF+`。

原理图说明“三路参考电压三者存其一”。在没有确认跳线/0 Ω 电阻状态前：

```text
不要修改 VREF 配置；
不要把外部电压直接接到 PA23/VREF+；
不要把 PA21/VREF- 当普通 GPIO 使用。
```

## 调试、复位和串口

| 功能 | 引脚/网络 | 规则 |
|---|---|---|
| SWDIO | `PA19/SWDIO` | 保留给 XDS110/SWD。 |
| SWCLK | `PA20/SWCLK` | 保留给 XDS110/SWD。 |
| Reset | `NRST` | 有 47 kΩ 3V3 上拉，按键接地。 |
| BSL | `PA18/BSL` | 有 47 kΩ GND 下拉，BSL 按键接 3V3。 |
| UART0 TX | `PA10/U0TX` | 板载 CH340E 串口路径。 |
| UART0 RX | `PA11/U0RX` | 板载 CH340E 串口路径。 |

> XDS110 出现连接问题时，优先确认 PA19/PA20 未被外部电路占用、NRST 可复位、PA18/BSL 未被意外拉高，再考虑恢复操作。
