## 可提供的数据

教程的 MSPM0 解析示例从 K230 跟踪数据中得到：

```text
x：目标框左上角横坐标
y：目标框左上角纵坐标
w：目标框宽度
h：目标框长度
```

这些是图像像素域数据。用于 H 题时，需要独立完成摄像头安装、摆杆坐标系定义、像素标定、滤波/延迟处理、无效帧处理和厘米误差验证。

## 当前控制职责（2026-07-30 更新）

K230 视觉链被指定为钢球位置外环的唯一测量来源，但教程例码输出的是目标框，不是可直接用于控制的厘米坐标：

```text
ball_center_px = (x + w/2, y + h/2)
ball_center_px
  → 投影到摆杆有效轴线
  → 相机/透视标定
  → ball_position_mm_relative_to_O（带符号）
```

控制数据至少还需要关联 `frame_id`、捕获时间、有效性和质量指标。若只有串口接收时刻，无法正确补偿摄像采集、推理和传输延迟。

当前级联关系为：

```text
K230 球位置 → 球位置外环 → 目标杆角/执行器位置
                              ↓
                 D36A + 步进电机 + MS42CG 内层反馈
```

MPU6050 不再安装于摆杆，也不用于修正杆角。杆角/右端高度必须由 MS42CG、机械零位和连杆几何映射建立；K230 不直接证明执行器已经达到目标角度。

### 必须验证

- 实际 K230 脚本发送的完整帧格式、波特率、帧率、时间戳、延迟和丢帧行为；
- 球心识别对反光、遮挡、运动模糊、振动和槽端位置的稳定性；
- 像素到毫米、O 点、正方向、有效行程与 `<= 1 cm` 验收方法；
- 视觉异常时禁止沿用旧位置，安全动作另行冻结。

## H 题边界

- K230 跟踪 + UART 坐标链路可作为钢球视觉检测的候选子系统。
- 该资料不包含视频发射、场外接收、显示、录像和回放方案，不能单独满足题目图传验收。
- 不将教程 `A21/A22` 映射为当前项目 `PA21/PA22` 或任意 MSPM0 引脚；禁止据此修改 `.syscfg`。
