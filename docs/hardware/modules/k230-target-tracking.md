## 已知接口信息

| K230 标注 | 当前角色 | MSPM0G3507 / 接口 | 当前结论 |
|---|---|---|---|
| `5V` | K230供电输入 | 独立稳定5 V电源 | 只用于供电；不得接MSPM0 RX或任何IO。接口pin4/5V按Pin Plan保持DNC；电流、纹波待测。 |
| `GND` | 参考地 | `USART1 pin3 / GND` | 单向UART必须共地；回流路径待台架核验。 |
| `TXD (IO9)` | K230 UART发送，3.3 V TTL | `USART1 pin1 / PA9 / UART1_RX` | 用户批准单向链路；115200 8N1、固定14字节帧；未实测。 |
| `RXD (IO10)` | 本协议不使用 | `USART1 pin2 / PA8 / UART1_TX` | 当前DNC；PA8仍由K230接口保留，不自动释放。 |

## 用户批准的UART协议设计（2026-07-31）

K230未来按115200、8N1单向发送固定14字节帧：

```text
55 AA STATUS SEQ POSL POSH VELL VELH CONF XL XH YL YH CRC8
```

`POS`和`VEL`为int16小端，单位分别为0.1 mm和0.1 mm/s；`X/Y`为uint16小端；CRC为CRC-8/ATM并覆盖前13字节。超100 ms无完整有效帧、丢球、卡帧或CRC错误时禁止继续使用旧坐标。详细定义见协议v1。


## 可提供的数据

教程的 MSPM0 解析示例从 K230 跟踪数据中得到：

```text
x：目标框左上角横坐标
y：目标框左上角纵坐标
w：目标框宽度
h：目标框长度
```

这些是图像像素域数据。用于 H 题时，需要独立完成摄像头安装、摆杆坐标系定义、像素标定、滤波/延迟处理、无效帧处理和厘米误差验证。

## 当前控制职责（2026-07-30 更新）

K230 视觉链被指定为钢球位置外环的唯一测量来源，但教程例码输出的是目标框，不是可直接用于控制的厘米坐标：

```text
ball_center_px = (x + w/2, y + h/2)
ball_center_px
  → 投影到摆杆有效轴线
  → 相机/透视标定
  → ball_position_mm_relative_to_O（带符号）
```

控制数据至少还需要关联 `frame_id`、捕获时间、有效性和质量指标。若只有串口接收时刻，无法正确补偿摄像采集、推理和传输延迟。

当前级联关系为：

```text
K230 球位置 → 球位置外环 → 目标杆角/执行器位置
                              ↓
                 D36A + 步进电机 + MS42CG 内层反馈
```

MPU6050 不再安装于摆杆，也不用于修正杆角。杆角/右端高度必须由 MS42CG、机械零位和连杆几何映射建立；K230 不直接证明执行器已经达到目标角度。

### 必须验证

- 实际 K230 脚本是否严格发送协议v1，以及帧率、延迟、抖动、连续预测和丢帧行为；
- 球心识别对反光、遮挡、运动模糊、振动和槽端位置的稳定性；
- 像素到毫米、O 点、正方向、有效行程与 `<= 1 cm` 验收方法；
- 视觉异常时禁止沿用旧位置，安全动作另行冻结。

## H 题边界
