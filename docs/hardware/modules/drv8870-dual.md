# DRV8870 双路直流电机驱动模块

> **资料状态**：模块手册 + 原理图 PDF 已复核；实物观察面和带载性能仍待验证。
> **权威接口来源**：`docs/reviewed/drv8870-dual-module-schematic-pdf-review.md`。
> **重要勘误**：旧 HTML 手册中的线性 H3 针序不用于本项目；H3 必须按原理图的 `2×4` 奇偶交错编号理解。

## 1. 电源与电流

| 项目 | 资料信息 | 本项目规则 |
|---|---|---|
| VIN | 模块资料推荐 `6.5–36 V`；驱动桥 `VBB=VIN`。 | 使用受保护的 3S 电池电机支路；不从开发板 USB/3V3 供电。 |
| 单通道持续/峰值 | 资料称持续约 2 A、峰值约 3.6 A。 | 两台车轮电机堵转电流用户陈述为每台 3.2 A；不允许长期堵转，必须验证限流、散热和温升。 |
| 5 V / 3.3 V | 模块带低压输出候选。 | 不与开发板或拓展板稳压输出并联，不用于反向给系统供电。 |
| 检流 | 原理图中每通道 100 mΩ，`VREF=3V3`。 | 实物版本、限流值和热行为未实测前不调整。 |

本项目冻结拓扑中，DRV 的 `VIN/GND/AOUT/BOUT` 均绕过拓展板电机功率铜线：

```text
3S 受保护电机支路 → DRV VIN/GND
DRV AOUT1/AOUT2   → 右轮电机（短粗线）
DRV BOUT1/BOUT2   → 左轮电机（短粗线）
```

## 2. H3 权威针序

H3 是 `2×4` 排针，按原理图焊盘编号：

```text
奇数列                 偶数列
1  AIN1                2  BIN1
3  AIN2                4  BIN2
5  EA1                 6  EB2
7  EB1                 8  EA2
```

| H3 焊盘 | 网络 | 本项目用途 |
|---:|---|---|
| 1 | `AIN1` | 右轮通道 A 控制输入 1。 |
| 2 | `BIN1` | 左轮通道 B 控制输入 1。 |
| 3 | `AIN2` | 右轮通道 A 控制输入 2。 |
| 4 | `BIN2` | 左轮通道 B 控制输入 2。 |
| 5–8 | `EA1/EB2/EB1/EA2` | 本项目 DNC；车轮编码器改由拓展板 U6/U16 四线直接进入 MCU。 |

> 上表确认的是电气焊盘编号，不确认实物插接面的左右方向。制作 H3 插头前必须拍到模块元件面、插接面和 Pin 1 标记，防止镜像接反。

## 3. 控制真值与安全状态

DRV8870 两输入基本真值：

| IN1 | IN2 | 状态 |
|---:|---:|---|
| 0 | 0 | 滑行/高阻候选安全态 |
| 1 | 0 | 一个方向驱动 |
| 0 | 1 | 另一方向驱动 |
| 1 | 1 | 制动 |

本项目采用“一个 Timer 输出 + 一个 GPIO”只表示资源分工，不得把 DRV8870 简化成普通的同极性 `PWM+DIR`：

- `IN2=0` 时，IN1 PWM 在驱动与滑行间切换；
- `IN2=1` 时，IN1 PWM 在制动与反向驱动间切换；
- 固件必须建立有符号占空比映射；
- 停车和换向先显式双低，等待经台架确定的死区，再切换方向；
- MCU 复位期 GPIO 为高阻，必须确认模块输入下拉或增加外部安全偏置后，才能声称上电无意外运动。

## 4. 与拓展板 U2 的关系

U2 原为 TB6612 模块接口，不能把 DRV8870 直接插入。最终方案只把 U2 的若干控制焊盘用作改线后的信号汇接点：

- 隔离 `PB9→U2 pad14`、`PB7→U2 pad12`、`PB6→U2 pad11`；
- 保留 `PB12→U2 pad15`；
- 桥接 `U2 pad16/PB14→pad14`、`U2 pad10/PA7→pad12`、`H1.17/PB24→pad11`；
- U2 电源、5 V、GND 和 AO/BO 功率焊盘不进入 DRV 电源或电机回路。

详细施工端点和断电检查见 `docs/pin-plan/mspm0g3507-adapter-harness.md`。
