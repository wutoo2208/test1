# D36A 双路步进电机驱动 - 硬件事实卡

> **状态**：`[候选|资料复核]`。D36A 是驱动模块，不是电机。  
> **详细来源**：[D36A 用户手册 PDF 复核](../../reviewed/d36a-dual-stepper-driver-user-manual-pdf-review.md)。

## 模块接口与控制

| 接口 | 作用 |
|---|---|
| `Vin+ / Vin-` | 手册示例的外部 12 V 输入。实际范围、保护与线束未确认。 |
| `A+ / A- / B+ / B-` | 两相双极步进电机的一路绕组输出。 |
| `ST1/ST2` | 两个通道的 STEP，上升沿有效。 |
| `DIR1/DIR2` | 两个通道方向。 |
| `EN1/EN2` | 两个通道使能，低休眠、高使能。 |
| `ADC` | 输入电压 1/11 监测输出（手册声明）。 |
| `5V` | 驱动板 5 V 输出；当前禁止与系统电源域直接并联。 |

## 电流与细分

- 共同拨码设置两路的细分和电流；支持全步、半步、1/4、1/8、1/16、1/32。
- 手册电流表最大档为 1.44 A、最小档为 0.55 A；电流定义、连续能力、温升和步进电机匹配须由实际电机资料/实测确认。

## 项目边界

- D36A 不替代 DRV8870；它用于两相步进电机，不用于当前两轮直流电机。
- 若用于摆杆/小球机构，其驱动链和 MS42CG 编码器链应独立建立接口、供电与安全限制。
- 未确认步进电机相电流之前，不得决定 D36A 电流拨码档位；未确认控制输入电平/时序前，不得分配 MSPM0 GPIO 或 Timer。
