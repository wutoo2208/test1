# MPU-6000A / MPU6050 模块

> **资料状态**：已审阅 MPU-6000/MPU-6050 寄存器手册和模块引脚定义 Word 文档。  
> **来源**：`rm-mpu-6000a-module.pdf` p10-13、p44、p49；`mpu6000a-pin-definition.docx`。  
> **结论边界**：模块 Word 文档描述了某模块版本；芯片寄存器手册覆盖 MPU-6000/MPU-6050 系列。实际模块丝印、I2C 上拉连接和芯片型号仍需实物核验。

## 1. 供电与 I2C 接口

| 信号 | 资料说明 | 工程规则 |
|---|---|---|
| `VCC` | 模块带 3.3 V LDO，文档称外部可供 3.3 V 或 5 V。 | 与 MSPM0 对接时优先给模块 **3.3 V**，避免模块 I2C 上拉到 5 V 的风险。 |
| `GND` | 地。 | 必须与 MCU 共地。 |
| `SCL` / `SDA` | 主 I2C 接口；模块文档称已有 4.7 kΩ 上拉。 | 与开发板 PA0/PA1 的板载上拉并存前，先确认总线上拉电压与等效阻值。 |
| `AD0` | 控制 I2C 地址最低位；有 10 kΩ 下拉。 | 悬空/接 GND：`0x68`；接 VDD：`0x69`。 |
| `INT` | 数据就绪时可发生电平变化。 | 可作为数据就绪中断候选；未分配 GPIO。 |
| `XDA` / `XCL` | 辅助 I2C 总线引脚。 | 当前不用作主 MCU 接口。 |

## 2. 身份、采样率、滤波与量程

| 项目 | 寄存器 | 资料事实 |
|---|---|---|
| 身份读取 | `WHO_AM_I`，`0x75` | 默认值 `0x68`。 |
| 采样率分频 | `SMPLRT_DIV`，`0x19` | `Sample Rate = Gyroscope Output Rate / (1 + SMPLRT_DIV)`；DLPF 使能时陀螺输出率 1 kHz，DLPF 关闭（0 或 7）时为 8 kHz。 |
| 低通滤波 | `CONFIG`，`0x1A` | `DLPF_CFG` 选择加速度计/陀螺仪带宽与延迟；资料列出 260/184/94/44/21/10/5 Hz 等档位。 |
| 陀螺量程 | `GYRO_CONFIG`，`0x1B` | `FS_SEL`：±250、±500、±1000、±2000 °/s。 |
| 加速度量程 | `ACCEL_CONFIG`，`0x1C` | `AFS_SEL`：±2、±4、±8、±16 g。 |
| 电源与时钟 | `PWR_MGMT_1`，`0x6B` | 可复位、睡眠、选择时钟源；资料建议使用陀螺仪 PLL 参考以提高稳定性。 |

## 3. 初始化顺序（参数未定，不代表当前代码）

```text
1. 确认 VCC/SDA/SCL/AD0/INT 的实物接线与 3.3 V 电平。
2. I2C 读取 WHO_AM_I(0x75)，期待 0x68；失败时停止，不猜测地址。
3. 通过 PWR_MGMT_1 复位/唤醒并选择时钟源。
4. 配置 CONFIG.DLPF_CFG。
5. 配置 SMPLRT_DIV 以得到所需采样率。
6. 配置 GYRO_CONFIG.FS_SEL 与 ACCEL_CONFIG.AFS_SEL。
7. 若使用数据就绪节拍，配置中断并读取 INT_STATUS。
8. 以连续 burst read 读取加速度、温度和陀螺数据，保持同一采样时刻的一致性。
```

## 4. H 题当前职责（2026-07-30 更新）

- H 题的钢球位置检测**必须采用摄像头**；当前方案以 K230 派生的钢球相对 O 点位置作为钢球位置唯一测量。
- MPU6050 **不再安装在摆杆上，也不作为摆杆角度反馈**。摆杆执行器的位置/角度内层由 MS42CG 与机械零位/连杆标定承担。
- MPU6050 改装在小车车体上，只作为车体角速度、加速度、倾斜、转弯状态或扰动前馈候选；TCRT5000 仍是循迹主反馈，车轮编码器仍是轮速主反馈。
- 在静态零偏、安装轴向、车体振动、温漂、延迟及 AB 对照测试完成前，MPU6050 数据默认只记录、不进入循迹闭环。不能依靠积分加速度/角速度长期推算赛道位置。
- 资料文档提到 100 Hz/10 ms 作为平衡车示例控制周期；这不是本题已经确认的采样或控制周期，应在系统辨识和实测后决定。
- 该职责变化不改变 frozen v1.2 中 PB2/PB3 I2C1 的设计端点，也不授权重新接线、修改 SysConfig 或上电。

## 5. 待确认

- 实物模块上芯片是否确为 MPU6050，而非兼容/替代芯片。
- 模块供电为 3.3 V 时，SDA/SCL 实测上拉电压与 I2C 地址是否为 0x68。
- INT 输出极性/驱动方式及是否需要外部上拉。
- 模块在车体上的固定位置和 X/Y/Z 轴方向；是否远离电机、驱动器和柔性振动结构。
- 静态零偏、温漂、车轮/步进电机振动频谱、滤波延迟，以及加入辅助项前后的循迹误差对照结果。
