## 已确认的来源事实

| 项目 | 事实 | 原 PDF 页码 |
|---|---|---|
| 传感器与比较器 | TCRT5000 红外反射器件；说明书写 LM393，电路图也标出 LM393。 | 说明书 p2；电路图 p1 |
| 供电 | 说明书写 3.3 V-5 V；接线段写 VCC 为 3-5 V 正极。 | 说明书 p2-p3 |
| 接口 | `VCC`、`GND`、`DO`、`AO`；连接器编号为 1=`VCC`、2=`GND`、3=`DO`、4=`AO`。 | 说明书 p3；电路图 p1 |
| 数字输出 | `DO` 是 TTL 开关量输出；反射弱/无反射时高电平，反射足够时低电平。 | 说明书 p3 |
| 模拟输出 | `AO` 是模拟信号输出；PDF 未规定传递曲线、范围或动态性能。 | 说明书 p3；电路图 p1 |
| 阈值调节 | 电路图标注 `VR1=10K`，说明书称带多圈可调精密电位器。 | 电路图 p1；说明书 p2 |
| 图纸输出上拉 | `DO` 经 10 kΩ 上拉至 `VCC`。 | 电路图 p1 |
| 单通道范围 | 说明书发货清单为一个寻迹模块；图中只出现一个 TCRT5000 和一个四针连接器。 | 说明书 p3；电路图 p1 |

## 接线前必须关闭的待确认项

1. **实际产品形态**：上传五路模块正反面和接口照片，或其专用说明书/原理图。当前 PDF 不足以证明五路一体板的通道、引脚或电平。
2. **逻辑电平**：若模块按电路图 5 V 供电，`DO` 上拉端在 5 V；必须在实物确认和获授权测量后，才能判断是否可接 MSPM0 的 3.3 V GPIO。
3. **循迹可用性**：距离 1 mm-25 mm 是说明书声明，不能代替赛道、黑线、环境光和安装高度下的标定结果。
4. **最终资源**：未选择 MCU 引脚、外设实例、采样频率、阈值或控制周期。

## 禁止外推

- 不把单通道 PDF 的 `DO/AO` 定义外推成“五路板的五路输出”。
- 不将“说明书支持 3.3 V”写成“实际板已与 MSPM0 安全兼容”。
- 不将资料复核写成通电、测量或循迹通过。
