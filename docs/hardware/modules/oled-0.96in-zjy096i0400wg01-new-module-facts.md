## 接线前规则

- **不要**把实物标记 `SCK` 自动当作 SPI；该型号资料将第 3 针定义为 I²C `SCL`，但实物修订还需确认。
- 可以将 OLED 供电和 I²C 逻辑电平分开思考：即使模块允许 5 V 供电，资料仍限制 SCL/SDA 最高 3.3 V。
- 不允许把天猛星 `GND/5V/PA1/PA0` 直接接到实物四针，直到确认插针方向和 PA0/PA1 的 I²C 角色。
- 不选择 MSPM0 I²C 外设、GPIO、地址或速率，直到 `VDD/VCC` 与 `SCK/SCL` 差异关闭。
