## PDF p1 确认的接口

| 接口/网络 | 已确认的图纸事实 |
|---|---|
| A 驱动控制 | `AIN1`→U2 `IN1`；`AIN2`→U2 `IN2`；电机输出为 `AOUT1/AOUT2`。 |
| B 驱动控制 | `BIN1`→U1 `IN1`；`BIN2`→U1 `IN2`；电机输出为 `BOUT1/BOUT2`。 |
| 逻辑/编码器 H3 | 1=`AIN1`、3=`AIN2`、5=`EA1`、7=`EB1`；2=`BIN1`、4=`BIN2`、6=`EB2`、8=`EA2`。 |
| 驱动供电 | 两颗 DRV8870 的 `VBB` 接 `VIN`；`VREF` 接 `3V3`；`LSS` 各经 100 mΩ 到 GND。 |
| 模块电源 | `VIN_IN` 经 SW4 到 `VIN`；XL1509-5.0E 产生 `+5V`；AMS1117-3.3 由 `+5V` 产生 `3V3`。 |
| 电机/编码器接口 | U40/U41 出现 A/B 电机输出、EA/EB、GND、3V3 网络。 |

## 与天猛星拓展板的可用边界

两份设计中 AIN/BIN、EA/EB、AOUT/BOUT 和功率/GND名称存在重合，故可作为**转接线束候选**进行设计；但不是“直接插接已验证”。

在写 Pin Plan 或接线前，必须关闭：

- DRV 实物是否与该原理图一致；
- 天猛星 TB6612 插座的物理针序和 DRV H3/U40/U41 的物理针序；
- `VBAT_IN`→`VIN_IN` 的供电、保险、开关、共地与禁止反灌拓扑；
- 控制输入的安全默认态、PWM 方式与 3.3 V 电平；
- 编码器 A/B 相、正反转和两个车轮的符号约定。

**禁止**把模块 `+5V` 或 `3V3` 电源输出直接并到天猛星/MSPM0 电源域，除非后续电源树审查明确允许。
