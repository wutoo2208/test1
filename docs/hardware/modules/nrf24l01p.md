# nRF24L01+ 无线模块 / 控制 IC

> **资料状态**：已审阅 nRF24L01+ IC 数据手册；未获得本次实际插针模块的正反面照片、排针丝印或模块原理图。

## 1. 供电与逻辑

| 项目 | 资料事实 | 工程约束 |
|---|---|---|
| IC 供电 `VDD` | `+1.9 V` 到 `+3.6 V DC`。 | MSPM0 对接时应以 **3.3 V 供电/逻辑** 为默认方案；禁止接 5 V。 |
| 地 | `VSS` 为 0 V。 | 与 MCU 共地。 |
| 主机接口 | SPI：`CSN`、`SCK`、`MOSI`、`MISO`；另有 `CE` 和低有效 `IRQ`。 | 具体模块排针顺序待实物丝印确认，不能只凭常见 8 针模块记忆接线。 |
| 空口速率 | `250 kbps`、`1 Mbps`、`2 Mbps`。 | 收发双方必须使用相同速率。 |
| RF 信道 | `F0 = 2400 + RF_CH [MHz]`。 | 收发双方必须使用相同 `RF_CH`。 |

## 2. 工作模式与寄存器方向

- 可配置为 Power Down、Standby、RX、TX；`CONFIG.PWR_UP` 控制上电状态，`CONFIG.PRIM_RX` 控制收/发方向。
- 速率由 `RF_SETUP` 中的 `RF_DR` 配置；发射功率由 `RF_SETUP.RF_PWR` 配置。
- 信道由 `RF_CH` 配置。
- 数据包与地址/自动应答/FIFO 等配置位于 SPI 可访问寄存器中；完整寄存器表见数据手册 p57 起。

## 3. 初始化记录模板（不代表当前固件设置）

在尚未确认无线用途、模块板型、天线形式和两端配置前，只记录推荐初始化顺序：

```text
1. 核对模块排针、3.3 V 供电和共地。
2. 令 CE 为低；确认 CSN/SCK/MOSI/MISO/IRQ 方向。
3. 通过 SPI 读取状态，清空 RX/TX 中断标志与 FIFO。
4. 设置地址宽度、TX/RX 地址、载荷长度和自动应答策略。
5. 设置 RF_CH、RF_SETUP（速率/功率），两端保持一致。
6. 写 CONFIG：上电、CRC、RX 或 TX 模式。
7. 按模式要求切换 CE，并记录 IRQ/发送结果。
```

## 4. 与 H 题的关系

H 题要求钢球位置监测装置能够稳定、实时显示视频并完整记录/回放。该 IC 数据手册只证明其最高 **2 Mbps 空口数据率**，**不能据此证明它可满足题目的视频图传要求**。在获得独立摄像头/视频发射接收模块规格与实测证据前，nRF24L01+ 只能视为低速控制、遥测或参数链路的候选，不能登记为图传方案。
