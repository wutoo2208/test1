## 2026-07-30 Pin Plan v1.0 Resolution

> 下列内容关闭的是**设计选择**，不是硬件实测。当前唯一资源基线见 `docs/pin-plan/mspm0g3507-pin-plan-frozen-v1.2.md` 和 `docs/pin-plan/mspm0g3507-adapter-harness-v1.2.md`。

### 已关闭的设计选择

- 无线：`DEFERRED`；v1.0 不保留任何 MCU 引脚、无电源线、无 SysConfig Owner。
- 五路循迹：使用五路一体 TCRT5000，经 H10 pin1–5 固定为 PB19/PB17/PA16/PA14/PB20。
- MPU6050：固定使用 PB2/PB3 的 I2C1；项目口语“U1”不等于 EPRO designator U1。
- K230：固定使用 USART1（PA8/PA9）；USART0 保留 CH340；USART2 future-reserved 且当前 DNC。
- DRV8870：U2 采用三隔离、三桥接、一保留；功率绕过拓展板；U3 不用。
- 左右轮编码器：U6 使用 PB10/PB11 QEI；U16 使用 PB4/PB5 双 Capture；U6/U16 两个功率针 DNC。
- 摆杆：D36A 只用通道1；MS42CG V2 使用 A/B/PWM/Z、VCC=3.3V，不改 SPI，不直插 U6/U16；RC 舵机路线取消。
- U12、H8、全部拓展板/开发板 KEY/LED 均不用。

### 仍开放的实物/电气问题

1. TCRT：OUT 高低电压、推挽/开漏、有效极性、车体左右顺序和电平转换。
2. U2/DRV：实际切线位置、桥接焊盘、H3 Pin 1/观察面、输入偏置、限流与温升。
3. U6/U16：连接器观察面、车轮编码器 PPR/CPR、相位、最高频率与正方向。
4. OLED/MPU6050：实物供电、地址、上拉位置/电压和总线等效阻值。
5. K230：3.3 V TTL、115200 8N1、固定14字节帧和CRC-8/ATM已形成用户批准设计；仍需实际波形/脚本/帧率/延迟、供电、预测降权/卡帧阈值、标定与完整视频图传链。
6. D36A：控制头观察面、3.3V 门限、STEP 脉宽/最高频率、EN/ST 硬件偏置、Vin、电流档、细分、风扇/散热和急停。
7. MS42CG：实际 V2 六针观察面、线束颜色、绕组针序、A/B 方向、PWM 帧率、Z 脉宽和机械安装零位。
8. H13：有源/无源、有效极性和 PB27 可承受的输入电流；无源方案不使用现有 v1.0 Timer 分配。
9. 电源：MP1584 实际输出、BMS、保险、回流、峰值能力和各模块负载瞬态。

这些开放项关闭前，不执行 PCB 切线、接线、`.syscfg`、上电或运动测试。

## Q-010 - 无线 SPI0 v1.2（已批准并冻结设计）

**Q-010 状态**：用户已批准 v1.2 资源与端点设计，并已生成 `docs/pin-plan/mspm0g3507-pin-plan-frozen-v1.2.md` 与 `docs/pin-plan/mspm0g3507-adapter-harness-v1.2.md`。这只关闭 Pin Plan 设计审批，不代表已完成 SysConfig、接线、供电或通信验证。

已冻结的设计结论：

1. 无线 SPI0 使用 `PB25 CSN`、`PB17 MOSI/PICO`、`PA12 SCK`、`PB19 MISO/POCI`，`PB1 CE`，`PB16 IRQ`。

3. TCRT OUT1/OUT2 改走 H10 pin7/pin8，即 `PA25/PA27`；OUT3/OUT4/OUT5 保持 `PA16/PA14/PB20`。
