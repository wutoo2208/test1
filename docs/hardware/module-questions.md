# 外设资料待确认问题

> 这些问题阻止最终接线、SysConfig 分配和上电。回答后再更新 `docs/hardware-interface.md` 的“已确认接线矩阵”。

## Q-001 - nRF24L01+ 的用途

你计划让 nRF24L01+ 在 H 题中承担什么任务？

```text
A. 低速遥测/参数调节
B. 两个 MCU 的控制数据通信
C. 题面要求的钢球位置视频图传
D. 其他（请说明）
```

> 若选择 C：现有 nRF24L01+ 数据手册最高只写到 2 Mbps 空口速率，不能作为满足实时视频图传要求的已验证方案；需要提供独立摄像头图传发射端、接收端和录像方案资料。

## Q-002 - 八路循迹模块的电平与发光颜色

请提供模块正反面清晰照片或回答：

1. 模块是白光、蓝光、绿光还是红光版本？
2. 模块供电 5 V 时，OUT 高电平实测是多少伏？
3. 你是否允许为 OUT 加 5V→3.3V 电平转换？

## Q-003 - MPU6050 模块的实际版本

请确认：

1. 模块 VCC 将接 3.3 V 还是 5 V？建议优先 3.3 V。
2. 模块丝印/芯片是否为 MPU6050？
3. 是否需要使用 INT 数据就绪引脚？
4. 模块相对车体的 X/Y/Z 安装方向如何定义？

## Q-004 - 双路 DRV8870 与 MG513X 电机

请提供或测量：

1. 两个 MG513X 的额定电压、堵转电流、减速比和编码器脉冲数；
2. 编码器供电和 A/B 输出电平；
3. DRV8870 模块正反面和 H3/电机接口丝印照片；
4. 计划使用的电池型号、额定电压和最大持续/峰值电流。

## Q-005 - H 题机械和图传资源

题面规定摆杆凹槽内钢球位置检测必须采用摄像头。请说明目前是否已经有：

```text
摄像头 + 车载视频发送模块 + 场外接收显示/存储设备
```

若没有，这一项是 H 题要求 1、4、5、6 的关键缺失硬件。`n`n## Q-006 - 天猛星拓展板与 MP1584EN 供电模块

已收到拓展板正面装配照片和一张 MP1584EN 参数图片；仍请补充：

1. 拓展板**背面**高清照片，以及两块顶端降压子板的正反面、芯片丝印、输入/输出标识；
2. 两块顶端降压子板是否就是 MP1584EN，分别准备输出什么电压、供给什么负载；
3. 独立 MP1584EN 模块的数量、目标输出（是否固定为 5 V）和计划负载；
4. 电池到拓展板/降压模块之间是否有保险丝、总开关、反接保护，电源极性如何确认；
5. 经单独 L3 授权后，能否先在无负载下测量每路输出电压，再决定是否接入主控或其他设备。

在这些信息确认前，不得把拓展板排针或 MP1584EN 输出写为已确认接线，也不得上电、调压或修改 SysConfig。
